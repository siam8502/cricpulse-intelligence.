# CricPulse

A mobile-first cricket intelligence and match-analysis project. Fixture information is sourced and timestamped; unavailable data is labelled clearly. Hypothetical simulations are kept separate from real statistics.

## Sources
- ICC fixtures: https://www.icc-cricket.com/fixtures-results?appview=true
- Cricbuzz schedule cross-check: https://www.cricbuzz.com/cricket-schedule/series
- Cricsheet historical data: https://cricsheet.org/
